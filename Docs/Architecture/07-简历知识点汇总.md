## 2. 项目描述示例（简历项目栏）

> **俯视角 ARPG 学习项目（Unreal Engine 5.3 + GAS）**
> - 基于 Gameplay Ability System 搭建完整战斗框架：自定义 ASC/AttributeSet（17 个可复制属性）、MMC 属性捕获计算派生属性（最大生命/法力随 Vigor/Intelligence/等级成长）、数据驱动属性 UI（Tag→Getter 函数指针映射实现属性菜单零代码扩展）；
> - 实现火球技能的全链路客户端预测：自定义 AbilityTask 采集鼠标目标数据（FScopedPredictionWindow + ServerSetReplicatedTargetData 带预测键上传），服务器挂起等待 + 补广播防网络竞态，SpawnActorDeferred 在生成前注入伤害 GE Spec，伤害服务器权威执行、表现层客户端本地播放；
> - 设计 Enhanced Input 数据驱动输入框架：InputAction ↔ GameplayTag ↔ 能力 Spec 三层映射，Pressed/Held/Released 三态分离，单键承载移动/技能双语义（长按移动、短按寻路、Shift 炮台模式）；Spline 缓存寻路路径实现自动寻路；
> - 搭建 UI MVC 架构：HUD 组装 WidgetController + 控件，控件只订阅 BlueprintAssignable 委托，与 GAS 零耦合；效果消息通过 GE AssetTags + DataTable 驱动；
> - 使用 C++ 模板/委托机制：静态函数指针 TMap、模板批量输入绑定，掌握 UE 委托体系与容器遍历安全（延迟删除防迭代器失效）。

## 3. 分点知识（面试自述素材）

### GAS 核心概念
- **ASC 归属设计**：玩家 ASC 放 PlayerState（跨关卡持久、重生安全、网络同步可靠），敌人 ASC 自持（Minimal 复制模式）；OwnerActor 与 AvatarActor 的区别（`InitAbilityActorInfo(PS, Character)`）；
- **属性回调钩子**：PreAttributeChange 只做 Clamp 不碰网络同步（预测模型约束）、PostGameplayEffectExecute 提取 Source/Target 上下文（OriginalInstigator 语义）；
- **GE 三形态与句柄**：Infinite GE 必须保存 FActiveGameplayEffectHandle 才能移除；
- **MMC 与 GameplayEffectExecutionCalculation 的区别**：MMC 用于单个 Modifier 的动态求值，ExecCalc 用于整体伤害公式（本项目用 MMC + 蓝图 GE）。

### GAS 网络与预测
- **预测键（PredictionKey）**：AbilityOriginalPredictionKey vs ScopedPredictionKey；FScopedPredictionWindow 作用域内网络操作自动携带预测键，服务器对账/回滚；
- **TargetData 管线**：本地采集（FGameplayAbilityTargetData_SingleTargetHit）→ ServerSetReplicatedTargetData → 服务器 AbilityTargetDataSetDelegate + CallReplicatedTargetDataDelegatesIfSet（防"数据先到委托后绑"竞态）→ SetWaitingOnRemotePlayerData 挂起 → ConsumeClientReplicatedTargetData 消费缓存；
- **ShouldBroadcastAbilityTaskDelegates**：能力激活窗口内才广播，防幽灵回调；
- **复制模式**：Mixed（玩家：GE 复制给所有者）/ Minimal（AI：仅属性同步）。

### 输入与操控
- **Enhanced Input**：UEnhancedInputLocalPlayerSubsystem::AddMappingContext、UEnhancedInputComponent::BindAction 的模板推导；
- **三态（Started/Completed/Triggered）** 与能力输入协议（AbilitySpecInputPressed/InputReleased 只标记不取消）；
- **客户端寻路**：bAllowClientSideNavigation 配置项（UE 默认寻路仅服务器）、FindPathToLocationSynchronously + Spline 路径缓存；
- **Custom Depth/Stencil** 后处理描边高亮，CursorTrace 五场景状态机（只在变化时更新渲染状态）。

### C++ 与工程化
- **模板**：`BindAbilityActions<UserClass, PressedFuncType, ...>` 批量绑定、`TStaticFuncPtr<FGameplayAttribute()>` 静态函数指针别名；
- **委托体系**：DECLARE_DYNAMIC_MULTICAST_DELEGATE（蓝图可绑）/ DECLARE_MULTICAST_DELEGATE（纯 C++）/ lambda 桥接；
- **数据驱动设计**：UDataAsset（输入映射、属性说明）+ UDataTable（消息文案）+ 枚举策略（效果应用/移除策略）+ GameplayTag（元数据传递）；
- **SpawnActorDeferred / FinishSpawning**：先注入数据再完成构造，避免初始化竞态；
- **容器遍历安全**：遍历 TMap 时延迟删除（HandlesToRemove 两段式）；
- **CoreRedirects**：重命名 C++ 类/属性/结构体时维护资产断链（DefaultEngine.ini）。

### 蓝图 / 动画
- **AnimNotify 发 GameplayEvent** 驱动技能流程：AnimNotify（发信号）→ ASC（分发）→ UAbilityTask_WaitGameplayEvent（接信号）→ 唤醒 GA——美术可自由调整出手帧；
- **MotionWarping** 攻击前转向目标（C++ 通过 BlueprintImplementableEvent 接口暴露给蓝图）；
- **UWidgetComponent** 世界空间血条 + 敌人直接充当 WidgetController。

## 4. 面试高频追问（提前准备答案）

1. **"ASC 为什么放 PlayerState 而不是 Pawn？"** → 跨关卡持久 / 重生安全 / 同步时机（见文档 02）。
2. **"客户端预测的整个流程？如果数据先到服务器、委托还没绑怎么办？"** → 预测键机制 + CallReplicatedTargetDataDelegatesIfSet 兜底（见文档 04）。
3. **"MMC 和 ExecutionCalculation 怎么选？"** → 单 Modifier 动态求值用 MMC（捕获属性 + 公式），整体伤害公式/多目标逻辑用 ExecCalc。
4. **"为什么 PreAttributeChange 里不做网络同步？"** → 预测执行时也会走该回调，碰网络会破坏 GAS 预测模型（官方文档明示）。
5. **"Infinite GE 为什么必须存句柄？"** → 无到期时间，主动移除的唯一凭证。
6. **"UI 为什么不直接读 AttributeSet？"** → MVC 解耦：Widget 只订阅 WidgetController 委托；初始值 + 变化统一走 Broadcast 两阶段，不漏事件。
7. **"伤害为什么只在服务器做？"** → 防作弊 + 单一权威；客户端只播表现，用 bHit 防止特效双播。
8. **"Enhanced Input 和旧 Input 的差别？"** → 数据资产化映射、Modifier/Trigger 链、三态事件、跨平台键位。
